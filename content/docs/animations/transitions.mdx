## Slide, Fade & Zoom

A keyed view switcher: change `transitionKey` and the outgoing view animates out while the new one animates in. Three variants cover the most common navigation metaphors — `slide` for drilling in, `fade` for tabs and settings, `zoom` for opening an item from a grid. `direction` controls whether the slide moves forward or backward.

/>

### Props Reference

| Prop            | Type                          | Description                                  | Default    |
| --------------- | ----------------------------- | -------------------------------------------- | ---------- |
| `transitionKey` | `React.Key`                   | Key identifying the current view — changing it triggers the transition | required |
| `variant`       | `'slide' \| 'fade' \| 'zoom'` | Transition style                             | `'slide'`  |
| `direction`     | `1 \| -1`                     | Slide direction (forward / backward)         | `1`        |
| `duration`      | `number`                      | Animation duration in seconds                | `0.25`     |
| `className`     | `string`                      | Additional CSS classes                       | `undefined`|

## Shared Element (Expandable Card)

A card that morphs into an expanded detail overlay. The card container, media, and title share `layoutId`s between collapsed and expanded states, so framer-motion interpolates them — keeping the user oriented about where the content came from. Dismiss with `Esc`, the close button, or the backdrop.

### Props Reference

| Prop             | Type              | Description                                      | Default     |
| ---------------- | ----------------- | ------------------------------------------------ | ----------- |
| `id`             | `string`          | Unique namespace for the shared layout ids       | required    |
| `title`          | `string`          | Card title (shared between states)               | required    |

| `mediaClassName` | `string`          | Classes applied to the media area in both states | `undefined` |
| `children`       | `React.ReactNode` | Extra body shown only in the expanded state      | `undefined` |

## Modal Sheet

A bottom sheet built on the `dialog` primitive — slides up from the screen edge with a drag handle. Best for tasks the user finishes and dismisses. Inherits focus trap, `Esc` close, and overlay behavior from the dialog primitive.

## Flip Card

A two-sided card that flips between front and back with a pure CSS 3D transform — no animation library needed. Works controlled (`flipped` + `onFlippedChange`) or uncontrolled (`defaultFlipped`), and toggles on click, `Enter`, or `Space`.

### Props Reference

| Prop              | Type                          | Description                            | Default     |
| ----------------- | ----------------------------- | -------------------------------------- | ----------- |
| `front`           | `React.ReactNode`             | Content of the front face              | required    |
| `back`            | `React.ReactNode`             | Content of the back face               | required    |

| `axis`            | `'x' \| 'y'`                  | Rotation axis (horizontal / vertical)  | `'y'`       |

## Circle Reveal

A clip-path transition that reveals a view as an expanding circle starting from the tapped point. Pass the click coordinates as `origin` (any CSS units) and toggle `open` — the overlay animates from `0%` to `150%` radius at that spot.

## Card Stack

Depth-stacked cards, iOS-sheets style: cards behind the front peek out scaled and offset. Drag the front card down past the threshold to dismiss it — with `recycle` it springs to the back of the stack.

<ComponentPreview
  name="card-stack"
  classNameComponentContainer="min-h-[500px] overflow-hidden"
  code={(await extractSourceCode('card-stack')).code}
  sourceCode={(await extractSourceCode('card-stack')).sourceCode}
  lang="tsx"
  hasReTrigger
/>

### Props Reference

| Prop              | Type                                    | Description                                   | Default     |
| ----------------- | --------------------------------------- | --------------------------------------------- | ----------- |
| `items`           | `{ id: React.Key; content: ReactNode }[]` | Cards to stack, in front-to-back order      | required    |
| `visibleCount`    | `number`                                | How many cards render in the stack            | `3`         |
| `dismissOffset`   | `number`                                | Drag distance (px) that dismisses the front card | `100`    |
| `dismissVelocity` | `number`                                | Flick velocity (px/s) that dismisses          | `500`       |
| `recycle`         | `boolean`                               | Send dismissed card to the back vs. remove it | `true`      |
| `onDismiss`       | `(id: React.Key) => void`               | Called with the dismissed card's id           | `undefined` |
